Read-only collector setup

Safe foundation only: no network connection or device command is implemented. A separately reviewed command profile and explicit written authorization are required before any future collection.

This page shows what you must provide: device endpoint and pinned host key, an external vault reference (never the password), an agent identity, and a time-bounded scope approval.

Setup order

  1. Register the device and verify its SSH host-key fingerprint out of band.
  2. Create a read-only account in your approved secrets manager, then enter only its opaque reference through the API.
  3. Register and activate the customer-side collector identity.
  4. Create a written, time-bounded scope grant with command/time/output budgets; a different operator approves it.
  5. Import a separately reviewed signed command profile in a later package. Until then collection remains blocked.
